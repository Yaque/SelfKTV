# SelfKTV Android 客户端

基于 [yaque/selfktv](https://github.com/yaque/selfktv) 基线工程（AGP 9.3.3 / Kotlin / minSdk 30）开发的个人 K 歌 App，界面与交互模仿「全民K歌」。

## 功能

### 🎵 歌房（歌曲列表）
- 服务端歌曲列表、实时搜索（歌名/歌手）、**下拉刷新 / ⟳ 按钮**（拉取服务器新上传、分离完成的歌曲）
- 每首歌显示可用模式标签：原唱 / 人声 / 伴奏 / 智能；分离进行中显示「⏳ 分离中…」

### 🎤 点歌页
- 封面大图 + 歌曲信息（支持打分的歌曲带 🎯 徽章）
- **四种演唱模式**任选其一（演唱中可随时切换）：
  - **原唱**：人声 + 伴奏完整效果，适合跟唱学习
  - **人声**：只有人声，听清唱细节
  - **伴奏**：纯伴奏，你就是主角（需分离完成或手动上传伴奏）
  - **智能**：开口唱自动消原唱，停唱后原唱接上
- 两个入口：「🎤 开始演唱（录音·打分）」/「📖 练唱（逐句跟唱·块状音准）」

### 🎶 K 歌界面（模仿全民K歌）
- 顶部：返回 + 小封面图（有封面才显示）+ 歌曲信息 + **实时音准得分**（大数字）
- **模式随时切换**：🎤原唱 / 🎙人声 / 🎧伴奏 / ✨智能 四个 chip 点击即切
- **人声 / 伴奏 / 录音 / 耳返 独立开关**：任意时刻开/关，自由混音
- **音准器 + 声音展示条同宽并排**：横向音准条实时显示你与目标旋律的音高偏差（绿色带内 = 命中），下方同宽麦克风声音展示条
- **打分**：对照服务端提取的参考旋律逐帧计分，结束弹出得分 + S/A/B/C 评级
- **本地实时耳返**（建议戴耳机）
- 大面积**滚动歌词**展示区（LRC 高亮跟唱，点击歌词跳转进度；纯文本歌词按整曲均匀滚动）

### 📖 练唱页（模仿全民K歌练唱）
- **块状音准提示器**：参考旋律以横向滚动色块（钢琴卷帘）呈现，你的音高以圆点轨迹叠加，命中变绿
- **逐句跟唱**：系统唱一句（示范）→ 自动倒回 → 只放伴奏你跟唱一句 → 自动进入下一句
- **自定义练习范围**：单选/多选任意歌词句；上一句/下一句/重来本句；练唱不保存录音，结束给出音准评分
- 右侧**旋转唱片**（圆形封面，播放时旋转）
- 进度条拖动、播放/暂停、重唱、结束
- **原唱音量**实时调节
- **麦克风能量条** + 录音状态提示
- 智能模式的消音引擎：基于麦克风能量自动控制原唱音量（灵敏度在「我的」页可调）
- 演唱结束自动**上传作品**到服务端

### 🎧 作品
- 我的录音列表（歌曲、模式、时长、时间）
- 在线试听、删除

### 👤 我的
- 账号信息、服务器地址
- 演唱设置：录音开关 / 原唱音量 / 智能消音灵敏度
- 修改密码、退出登录

## 构建

### 环境要求

- Android Studio（Ladybug 或更新）+ JDK 17+（AGP 9 自带 Kotlin 支持）
- Android 设备或模拟器（minSdk 30 / Android 11+）

### 步骤

1. Android Studio 打开 `selfktv/` 目录
2. 等待 Gradle 同步（自动下载依赖：OkHttp、Material、RecyclerView 等）
3. 连接手机（开启 USB 调试），点 ▶ Run

命令行构建：

```bash
cd selfktv
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

> 命令行构建需要 Android SDK：在 `local.properties` 中写入 `sdk.dir=/path/to/sdk`。

## 使用

1. 先部署服务端（见 [../server/README.md](../server/README.md)）并在网页管理页**初始化账号 + 上传歌曲**
2. App 首次启动填服务器地址（如 `http://192.168.1.100:8000`）+ 账号密码登录
3. 歌房选歌 → 选模式 → 开始演唱

## 权限

| 权限 | 用途 |
| --- | --- |
| `INTERNET` | 访问服务端 API / 流媒体 |
| `RECORD_AUDIO` | K 歌录音、智能模式检测演唱状态 |

> 录音采集麦克风声音（伴奏经扬声器外放，属常规 K 歌体验）；未授予麦克风权限时智能消音与录音不可用，但试听不受影响。

## 代码结构

```
app/src/main/java/com/aiocw/selfktv/
├── SelfKtvApp.kt              # Application 初始化
├── data/Prefs.kt              # 本地偏好（服务器、令牌、演唱参数）
├── net/
│   ├── ApiClient.kt           # OkHttp 封装：登录/歌曲/流媒体/作品上传
│   └── Models.kt              # Song / Work 数据模型
├── audio/
│   ├── LrcParser.kt           # LRC 歌词解析
│   └── WavRecorder.kt         # 麦克风 WAV 录音 + 实时音量回调
└── ui/
    ├── LoginActivity.kt       # 登录
    ├── MainActivity.kt        # 底部导航（歌房/作品/我的）
    ├── SongsFragment.kt       # 歌曲列表 + 搜索 + 刷新
    ├── SongDetailActivity.kt  # 点歌页（四模式选择）
    ├── KaraokeActivity.kt     # K 歌界面（核心）
    ├── PracticeActivity.kt    # 练唱：逐句跟唱 + 块状音准
    ├── WorksFragment.kt       # 作品列表
    ├── ProfileFragment.kt     # 我的/设置
    ├── UiKit.kt               # 主线程调度/封面加载/工具
    └── widget/
        ├── LyricView.kt       # 滚动歌词控件
        ├── PitchMeterView.kt  # 音准器（横向偏差条）
        └── PitchRollView.kt   # 块状音准提示器（钢琴卷帘）
```
